# 画面Jev (screen-jev)

Macの画面を常に見て文字として記録し、Claude Code に話しかけた瞬間「直近の画面状況」を自動で渡すツールです。毎回「今こういう画面を見ていて…」と説明しなくてよくなります。Mac専用です(Windows非対応)。

## 何ができるか

- 5秒おきに最前面のアプリ/ウィンドウを確認し、変わったとき(または30秒経ったとき)にそのウィンドウの文字を読み取って記録します
- 5分おきに画面全体も読み取ります
- Claude Code に話しかけると、直近10分のアプリの移り変わりと「直前に見ていた画面(ターミナル以外)」の文字が自動で渡ります

## 前提

- macOS
- Xcodeコマンドラインツール(`swiftc`が使えること。無ければ `xcode-select --install`)
- ターミナル(または使っているターミナルアプリ)に「画面収録」の許可

## 入れ方

```bash
git clone https://github.com/Ryoseiimai/screen-jev.git ~/screen-jev
cd ~/screen-jev && ./install.sh
```

これだけで、見張りが起動し、Claude Codeの設定にフックが追記されます(既存の設定は消しません。自動でバックアップも作ります)。

特定プロジェクトだけに入れたい場合:

```bash
./install.sh --project ~/dev/あるプロジェクト
```

初回、macOSから「画面収録」の許可を求められたら許可してください。許可していない場合は `sjev status` に案内が出ます。

## プライバシー

- 撮った画像はその場でOCRしたら**即削除**します。画像は一切残りません
- 文字の記録は自分のMac内の `~/.screen-jev/timeline.jsonl` にのみ、**24時間だけ**残ります
- 1Password・キーチェーンアクセス等のアプリや、タイトルに「password」「暗証」等が含まれる画面は**撮影自体をスキップ**します
- APIキーらしき文字列(Anthropic/Google/GitHub/Stripe/AWS/Slack等)・JWT・カード番号らしき数字列・メールアドレス・日本の電話番号・「パスワード:」等のラベルの後ろの値は記録前に自動で `[伏せ字]` に置き換えます
- **正直な限界**: 除外はアプリ名・ウィンドウ名の一致だけで、画面の中身までは判定していません。短い記号混じりのパスワードや、上記のどのパターンにも当てはまらない独自形式の鍵は伏せきれない場合があります。パスワード入力欄は通常●●●で表示されるため、文字としては読み取られません(OCR対象外)
- 外に出るのは2つだけです。①Claude Codeに話しかけたとき、直近の画面の文字(伏せ字済み・2,500字まで)がClaude(Anthropic)に渡ります ②Jevを明示的にオンにした場合だけ、伏せ字済みの文字がJevに送られます
- `claude -p` などの無人実行には渡しません

### Jevへの送信をオンにする

Jevは TypeSafe AI 社の判定専用AIです(https://typesafe.ai)。入力を学習には使わないと公表しています(https://typesafe.ai/privacy)。**既定はオフ**で、`~/.config/typesafe/api_key` に鍵ファイルがあるだけでは送信されません。

1. 鍵ファイルを置く(場所は環境変数 `SJEV_JEV_KEY_FILE` で変更可)
2. `~/.screen-jev/config.json` の `"jev"` を `true` にする

オンにすると、除外・伏せ字処理を通した後の画面の文字が、判定のためにJevへ送られます。


## 止め方

```bash
./bin/sjev pause 30m   # 30分だけ止める(1h, 90sなども可)
./bin/sjev resume      # 再開
./uninstall.sh         # 完全に外す(記録データはバックアップとして残す)
```

## 状況確認

```bash
./bin/sjev status   # 動いているか・最終記録・件数
./bin/sjev now       # いまClaudeに渡る内容と同じものを表示
./bin/sjev log 30m   # 直近30分の記録を表示
```
